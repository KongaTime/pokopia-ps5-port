# Fonts of the start screen

Built into the title (ps5/game/title_screen.cpp), all under the SIL Open Font License 1.1 (licence text beside each):

| File | Used for | From |
|---|---|---|
| `Montserrat-Medium.ttf` | the menu (PLAY, EXIT) and the name when there is no logo.png | [Montserrat](https://github.com/JulietaUla/Montserrat) |
| `Inter-SemiBold.ttf` | messages, the progress text | [Inter](https://github.com/rsms/inter) |
| `KaTeX_Main-Italic.ttf` | RECOMP under the name | [KaTeX](https://github.com/KaTeX/KaTeX) fonts (MathJax TeX fonts) |
